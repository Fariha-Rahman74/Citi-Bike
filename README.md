# Citi-Bike
This Citi is Biking
Project Overview
This project examines Citi Bike ridership patterns between January 2024 and December 2025.
Research Question
How does Citi Bike usage differ between subscribers and casual riders, and how do riding patterns change by season and time of day?
Dataset
Official Citi Bike System Data.
Methodology
The project uses Python and pandas to process Parquet files and summarize ridership patterns.
The analysis examines:
Subscriber and casual rider usage
Seasonal ridership
Monthly ridership
Time-of-day patterns
Trip duration
Popular starting stations
Repository Contents
Data/: Raw and processed datasets
Notebooks/: Annotated Jupyter Notebook
Output/: Summary CSV files and analysis results
README.md: Project documentation
Findings
Final findings are presented in the accompanying project article and summary CSV files
